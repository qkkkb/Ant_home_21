# Ant_Home

`Ant_Home` 是一个面向智能车/双车协同场景的 MicroPython 项目，包含主控逻辑、第二辆车控制逻辑、视觉识别与标定相关代码。

## 目录结构

```txt
Ant_Home/
  Control/    主车控制、协同协议和运行入口
  NO.2/       第二辆车或从车相关控制代码
  Vision/     视觉识别、图像处理和 IPM 标定代码
  AGENTS.md   协作、Git、文档和 MicroPython 约束
```

## 开发约束

本仓库的协作规则记录在根目录 `AGENTS.md`。在修改代码、提交或推送前，请先阅读该文件。

关键约束包括：

1. `D:\Ant_Home` 内的代码或文档修改完成后需要提交到 Git。
2. 提交信息必须使用中文，并且只提交本次任务相关文件。
3. 推送前需要检查 `README.md` 是否需要同步更新。
4. MicroPython 代码应优先按内存受限设备优化，避免在热循环中反复分配对象。

## 说明

当前 README 只保留项目级入口信息。硬件连接、标定流程、运行步骤和调试记录后续可以拆分到 `docs/` 目录，并在这里链接。
