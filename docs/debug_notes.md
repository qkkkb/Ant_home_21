# Ant_Home 调车调试笔记

这个文件用于把每次调车从“贴大量日志然后凭感觉改”变成“带假设的小实验”。每轮调试只验证一个主要问题，记录现场、版本、日志、改动和结论，方便下一次继续时不用重新翻聊天记录。

## 使用原则

1. 每次调车前先写“本轮目标”和“只验证的假设”。
2. 日志只贴关键片段，优先贴异常前 10 行、异常后 30 行；完整日志写文件路径。
3. 不同时改多个方向、多个 PID、多个状态机条件；否则很难判断哪一处生效。
4. 每轮结束必须写结论：通过、未通过、部分通过，和下一步只做什么。
5. 和 Codex 协作时，把“本轮调试卡片”直接复制到 prompt 开头。

## 日志粘贴格式

贴日志时优先保留状态跳转和控制输出，不要只贴中间一堆重复行。

```text
现象一句话：

异常前：
[贴 5-10 行]

异常发生：
[贴 10-20 行]

异常后：
[贴 10-20 行]

我观察到：
1. 
2. 

请 Codex 只判断：
坐标符号 / 控制方向 / PID 参数 / 前馈 / 状态机 / 通信延迟 / 日志不可见
```

## 常用日志字段速查

| 标签/字段 | 关注点 | 常见判断 |
| --- | --- | --- |
| `[NAV]` | 主车状态机跳转 | 是否过早进入下一状态，是否反复跳转 |
| `[VISION]` | 视觉目标出现/丢失 | `age` 是否过大，是否拿旧目标继续控制 |
| `[FIELD]` | 场地方向和发射方向 | 判断角度基准是否对齐 |
| `[MAP]` | 从车视觉误差映射 | `err`、`cam`、`body`、`out` 符号是否一致 |
| `[TURN]` | 从车旋转闭环 | `yaw_err`、`cmd`、`gyro` 是否同向收敛 |
| `D0` | 主车高层状态 | `st`、`cam`、`wz/gz/vz` 是否符合当前阶段 |
| `D1` | 编码器和目标速度 | `enc` 与 `tgt` 是否方向一致 |
| `D2` | PWM 和输出 | `pwm/out` 是否饱和、是否被平滑拖慢 |

## 排查顺序

### 1. 方向反或正反馈

先不要调 PID，先判断符号链路。

| 检查项 | 记录 |
| --- | --- |
| 目标在车前时，视觉误差正负 |  |
| 目标在车后时，视觉误差正负 |  |
| 目标在车左时，横向误差正负 |  |
| 目标在车右时，横向误差正负 |  |
| 映射到车体系后的 `body` 符号 |  |
| 输出 `out/tgt/pwm` 是否让误差变小 |  |

结论：

```text
是视觉坐标符号错 / 车体系映射错 / 电机输出方向错 / 前馈符号错 / 不确定
```

### 2. 后退慢或推后响应慢

先区分“目标速度给小了”和“速度给到了但底盘没响应”。

| 检查项 | 记录 |
| --- | --- |
| 状态机是否进入后退状态 |  |
| 后退持续时间 |  |
| `tgt` 是否达到期望速度 |  |
| `pwm/out` 是否被限制或平滑 |  |
| 编码器是否跟上 |  |
| 是否有静置/收稳逻辑拦截 |  |

结论：

```text
是状态机问题 / 速度目标问题 / PWM 平滑问题 / 电机响应问题 / 收稳逻辑问题
```

### 3. 旋转超调或震荡

先看角度误差是否在变小，再看角速度闭环是否过强。

| 检查项 | 记录 |
| --- | --- |
| 目标角度 |  |
| 当前角度/陀螺积分角 |  |
| `yaw_err` 是否单调变小 |  |
| `cmd` 与 `gyro` 是否反向制动 |  |
| 小角度时是否进入死区 |  |
| 是否存在最小转速过大 |  |

结论：

```text
是角度基准错 / 角速度方向错 / P 太大 / D 或制动不足 / 最小输出过大 / 死区太小
```

### 4. 视觉坐标抖动或目标丢失

先确认是不是拿旧目标、误检目标或帧率不足。

| 检查项 | 记录 |
| --- | --- |
| 视觉帧率 |  |
| `age` 最大值 |  |
| 目标是否连续出现 |  |
| 坐标是否跳变 |  |
| 丢失目标后的保持策略 |  |
| 是否需要滤波或限幅 |  |

结论：

```text
是视觉误检 / 目标丢失保持太久 / 坐标噪声 / 滤波延迟 / 控制太敏感
```

### 5. 主从通信或无线日志影响

通信问题先确认“能不能看到”，再确认“看到的是不是旧数据”。

| 检查项 | 记录 |
| --- | --- |
| 主车是否发送 |  |
| 从车是否接收 |  |
| 数据时间戳/age |  |
| 无线日志是否开启 |  |
| 开启日志后是否丢包或延迟 |  |
| 是否需要临时关闭某类日志 |  |

结论：

```text
是未发送 / 未接收 / 接收旧数据 / 日志占用带宽 / 解析字段错 / 不确定
```
